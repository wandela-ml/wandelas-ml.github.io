Featured Projects

🏪 Tobhe – Business Oversight & Self-Service Checkout

Tobhe is a Python-based business oversight application designed to help Kenyan businesses manage branch operations, inventory, customer orders, and payments.

The deployed MVP includes branch operations, inventory management, customer order processing, and payment integration. It uses Safaricom Daraja's M-Pesa Express API to initiate customer payment requests and receive payment callbacks. Callback results are used to update payment and order records.

The project addresses a practical business challenge: helping owners gain better visibility into their operations while supporting more reliable order and payment management.

Status: MVP Deployed

Technologies: Python, SQLite, JavaScript, HTML, CSS, Safaricom Daraja API.

🎓 NafuLearn

An AI-powered learning platform designed around Kenya's Competency-Based Curriculum (CBC), currently focused on Grade 10 Computer Studies.

The project combines curriculum content, document chunking, Gemini embeddings, semantic retrieval, and Retrieval-Augmented Generation (RAG) to support learning explanations, student practice, answer evaluation, feedback, and retry functionality.

NafuLearn – RAG Architecture

Student Question or learning request
→
FastAPI Backend Receives and processes request
→
Gemini Embeddings Converts query into a vector
→
ChromaDB Retrieves relevant curriculum content
Retrieved Context Relevant learning material
→
Gemini LLM Generates a grounded response
→
Student Explanation and learning feedback
